Encryption

Optional AES-GCM encryption before drafts are written to disk. The key is derived with PBKDF2 and the passphrase is never stored. It stays in memory until you quit the browser. If you forget it, encrypted drafts cannot be read.

Sites to skip

One domain per line. Subdomains are included. Banking and payment sites start off so Typeback does not keep what you type there. Add or remove any host.
